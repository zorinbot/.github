## About

Zorin is a music bot built around three things: **speed, quality and minimalism**. Every message is short and easy to read, every command answers right away, and nothing clutters your channels.

This organization holds the code behind the Zorin ecosystem — from the website to the services that keep the bot running smoothly.

<br />

## Get started

```
1. Invite Zorin        →  go.zorin.app/invite
2. Join a voice channel
3. /play <song or link>
```

That's it. You're listening.

- **Levels** — every minute you listen earns XP, with bonuses for listening with friends, discovering new tracks and keeping a daily streak.
- **Leaderboard** — the ranking resets every Monday, and the top 10 listeners across Zorin win coins every week.
- **Economy** — earn coins by listening, claim `/daily`, send coins with `/pay` and share `/giftcode create`. Your profile goes with you to every server.

<sub>XP and coins have no real-world value and can't be bought or sold. See the <a href="https://zorin.app/terms#virtual-economy">Terms</a>.</sub>
